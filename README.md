# sv-parse · 短视频解析下载

单文件网页版：粘贴抖音 / 快手 / B 站分享链接，一键解析无水印视频与图集，浏览器内直接下载。

## 在线使用

**https://a1983450442-coder.github.io/sv-parse/**

手机与电脑浏览器均可打开，无需安装、无需登录、无需本机常开。

## 用法

1. 复制抖音 / 快手 / B 站 App 里的分享文案或链接。
2. 打开网页，粘贴进输入框（一行一条，可批量）。
3. 点「开始解析」，等待卡片出现。
4. 选好画质，点「下载视频」；图集点「下载全部图片」。

## 支持平台

| 平台 | 状态 |
| --- | --- |
| 抖音 | 无水印，支持短链与分享文案 |
| 快手 | 无水印，多画质 |
| B 站 | 支持多分P |
| 小红书 / 视频号 / 皮皮虾 等 | 走聚合接口，随上游可用性变化 |

## 技术说明

- 纯前端静态页，无后端、无数据库、无账号。
- 解析走公开 API；视频直链来自 CDN，页面请求带 `referrerPolicy: no-referrer` 以绕过防盗链。
- 下载方式为浏览器内流式读入 Blob 后触发保存，失败时回退到新窗口打开（长按 / 右键保存）。

## 已知限制

- 依赖第三方公开解析接口，接口限流或调整时可能短暂不可用。
- iOS Safari 首次下载可能需要在「文件」App 中确认保存位置。
